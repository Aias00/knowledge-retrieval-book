# 附录B 实验记录与复现坐标

本次实验日期为 2026-10-21，使用 Python 3.12.15 与 SQLite 3.53.1。所有制度、身份、秘密标记和查询均为作者构造。记录不是独立业务验收集、模型排行榜或生产性能基准。

## 输入与核心证据

语料版本 `knowledge-fixture-v1`，八篇文档，十三条查询，其中十条正例、三条负例。`lab/data/manifest.json` 保存 `corpus.json` 与 `queries.json` 的 SHA-256，加载时自动复核，避免报告与输入无声错位。

`lab/evidence/demo.json` 记录真实 SQLite 操作：退款三十天改十四天、旧引用失效；Alice 撤权后旧引用与新搜索拒绝，Bob 保持访问；年假删除后不再可检索，旧事件重放拒绝；私有、跨租户、无关查询计数均为零。回答标明 `non_llm=True`。

`term-evaluation.json` 保存词项基线逐条结果，三个模式 Recall@3 与 MRR@3 均为零点九。`bge-evaluation.json` 保存真实量化模型结果，词面零点九，向量与混合一点零；所有模式负例空候选三次、权限断言零违规。

`tokenizer.json`：439,125 字节，SHA-256 `48cea5d44424912a6fd1ea647bf4fe50b55ab8b1e5879c3275f80e339e8fae26`。

运行库为 ONNX Runtime 1.31.0、NumPy 2.5.4、tokenizers 0.23.3，CPU 执行提供方，单线程，CLS、L2、五百一十二维、最长五百一十二 token。查询带中文检索指令，文档不带。演示最小余弦值零点四，没有进行相关性概率校准。

## 测试与发布验证分开

核心测试二十二条；可选模型测试两条。本地设置 `BGE_MODEL_DIR` 后二十四条全部实际通过；无模型的 CI 则运行核心二十二条并跳过两条。跳过不计为模型通过，CI 不重复下载权重。

出版验证检查书稿与在线页、EPUB 的内容映射，EPUBCheck 验证格式；浏览器检查浅色默认、深色切换、字号记忆、全书搜索、目录、无脚本阅读与存储禁用。它们能发现出版与交互缺陷，不能证明书稿事实或检索业务效果。

报告的 `wall_ms` 是本机单次查询观察值，允许其他机器不同；状态变化、语料指纹、授权结果与相关文档排名才是本实验的主要复现对象。公开构建的精确提交、EPUB 字节和 CI 地址以仓库 `DELIVERY.md` 为准，避免在正文中嵌入会自我改变构建的产物摘要。
